Engineering decisions

The parts I'd defend in a design review.

No NAT.
No internet gateway.

The VPC is private subnets only. Lambda reaches Bedrock, Secrets Manager and S3 through VPC endpoints, so model and database traffic never touch the public internet, and the NAT bill is zero.

3 VPC endpoints · 0 egress paths

It defends itself.

A CloudWatch alarm on request volume fires a Lambda that drops the API stage throttle to zero. An abuse flood is rejected at the front door, unbilled, and it reopens automatically once traffic normalises.

ALARM → 0/0 · OK → 5/10

Keyless deploys.

GitHub Actions authenticates to AWS through OIDC. There is not a single static credential in the repo or in CI. Push to main and Terraform plans, applies and ships the Lambda bundles.

100% Terraform · 0 stored secrets
